# Code signing policy

This document is the policy template for a future SignPath Foundation
application. bwReplacer releases are currently unsigned; no SignPath credentials or
signing workflow are configured yet.

Once signing is enabled, this policy will identify the project committers,
reviewers, and release approvers, and will state that only artifacts built by
the protected GitHub Actions release workflow may be submitted for signing.

Free code signing will be provided by SignPath.io, certificate by SignPath
Foundation. The final policy will be completed before a SignPath application is
submitted and will include the project privacy statement required by SignPath.
