# Changelog

All notable changes to bwReplacer will be documented in this file.

## [1.5.0]

### Changed

- Migrated from PyQt6 into PySide6.

## [1.4.0]

### Changed

- Migrated from PyQt4 into PyQt6.

## [1.3.0]

### Added

- Added an All option to the corrections-table filter combo boxes.
- Added a toolbar.
- Added an expanding log, log files, and saved log options.
- Added search to the corrections table.

### Changed

- Converted the wiki into `README.md`.
- Updated the English TV database.
- Updated the Finnish TV database.

## [1.2.0]

### Added

- Added a log.

### Changed

- Updated the English TV database.
- Updated the Finnish TV database.

## [1.1.2]

### Changed

- Removed the restriction on application updates when fixing files.

### Fixed

- Fixed a bug in the regular-expression rules.
- Fixed a bug with the Start button.

## [1.1.1]

### Added

- Added a Fix menu.

### Changed

- Reordered the layout and tab order.
- Rewrote all regular-expression rules.
- Updated the English TV database.
- Updated the Finnish TV database.

### Fixed

- Fixed a bug with checkbox selections in tables.

## [1.1.0]

### Added

- Added drag-and-drop support for files to fix.
- Added more versatile options to the file-list table.
- Added file sizes to the file-list table.
- Added icons for actions, buttons, and tabs.

### Changed

- Removed the Fix tab; batch fix is now Fix.
- Adopted the new-style PyQt signals.
- Updated the English TV database.
- Updated the Finnish TV database.
- Changed UTF-8 output to UTF-8 with BOM.
- Changed version numbering.
- Saved window geometry.

### Fixed

- Fixed a bug when deleting a list.
- Fixed a bug when opening the database from settings.

## [1.01]

### Changed

- Added regular-expression testing before updating a correction with mode 1.
- Updated the English TV database.
- Updated the Finnish TV database.

### Fixed

- Fixed the wiki link.

## [1.00]

### Added

- Initial release.
